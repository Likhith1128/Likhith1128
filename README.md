## Flutter framework

Flutter is Google's UI toolkit. You write the interface in Dart, and Flutter compiles it for iOS, Android, web, Windows, macOS, and Linux. It draws its own pixels with the Impeller (or Skia) engine, so layout and motion stay consistent across those targets.

The framework is organized in layers:

| Layer | Role |
| --- | --- |
| **Dart app** | Your widgets, state, and business logic |
| **Framework** | Widgets, rendering, animation, gestures, and the Material / Cupertino libraries |
| **Engine** | Graphics, text, I/O, and the Dart runtime, mostly in C++ |
| **Embedder** | Platform windowing and input for each operating system |

A Flutter UI is a tree of widgets. Widgets are immutable descriptions of the interface. When state changes, Flutter rebuilds the affected part of the tree and updates the screen. Hot reload pushes Dart changes into a running app so you can iterate without a full restart.
